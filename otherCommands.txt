Undo or redo changes

git log 

git revert <hash>


git revert
Purpose:
Creates a new commit that undoes the changes of a previous commit.
git revert <commit>

1- public undo
2- Does not delete history
3-Safe for shared/public branches
4-Used in production environments


git reset
Purpose:-
Moves the branch pointer backward to a previous commit and can remove commits from history.

1- Local undo
2- Rewrites history
3- Dangerous for shared branches
4- Best for local work only

git reset --soft <commit>    --soft	Keeps changes staged
git reset --mixed <commit>   (default) --mixed	Keeps changes unstaged
git reset --hard <commit>    --hard	Deletes changes completely
